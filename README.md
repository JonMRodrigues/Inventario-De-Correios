# AUDITORIA-DOS-CORREIOS
Sistema web de auditoria de objetos dos Correios. O auditor escolhe nome e fluxo (saída, devolução ou outros) e bipa os códigos, aceitando e extraindo o padrão AD...BR. Bloqueia códigos inválidos e duplicados, conta as peças (limite de 2.500), permite consultar a lista e exporta tudo para Excel. Dados salvos no navegador, visual Windows XP.
